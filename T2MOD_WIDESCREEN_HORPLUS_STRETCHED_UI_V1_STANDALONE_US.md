# TMNT2 T2Mod Widescreen HorPlus Stretched UI v1 Standalone US

US/NA x86 EXE-only source branch for the standalone final widescreen package.

- Preserves vertical FOV and expands horizontal FOV to the active aspect ratio.
- Expands the RenderWare 3D camera frustum for correct Hor+ rendering.
- Keeps the original 2D HUD and menus intentionally stretched from 4:3.
- Labels detected 16:9 resolutions in Options > Display.
- Includes shared buffered runtime diagnostics.
- Does not include Intro Skip, MSAA, difficulty, or playable Slashuur changes.
- Does not rebuild or replace `TMNT.DAT` or any LPAC resource.

Source baseline: `dabccc3e3dc02c8a01eac1638fe1aeb589e2723b`.

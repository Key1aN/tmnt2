# TMNT2 T2Mod MSAA Frame State Lock v4 Standalone US

US/NA x86 EXE-only source branch for the standalone final MSAA package.

- Adds OFF, 2X, 4X, and 8X choices to Options > Display.
- Applies MSAA only in fullscreen mode.
- Verifies and repairs the active Direct3D 9 multisample surfaces.
- Preserves the confirmed frame-begin state lock and RenderWare cache sync.
- Includes shared buffered runtime diagnostics.
- Does not include Intro Skip, widescreen, difficulty, or playable Slashuur changes.
- Does not rebuild or replace `TMNT.DAT` or any LPAC resource.

Source baseline: `dabccc3e3dc02c8a01eac1638fe1aeb589e2723b`.
